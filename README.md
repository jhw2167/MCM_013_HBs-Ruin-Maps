# HB's Ruin Maps & Boss Bridges


    Simple mod which adds maps to route the player towards modded structures using dynamically
    generated maps, like treasure maps but with greater bounds.
    
    With the bosses, any Ender Eye (or modded variant) can be used a a dimensional bridge
    structure to activate it and a pair will spawn near the nearest boss structure (where the Ender eye leads).
